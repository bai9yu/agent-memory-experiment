# Memory Feature 参数搜索报告

## 输入

使用 `memory_eval.py` 生成的 `rankings.csv` 作为候选级特征缓存，直接重排已落盘候选集合。这个步骤不需要重新加载 BGE-M3，也不需要重新计算 BM25，因此适合快速扫权重。

注意：该缓存只覆盖每个 query 已保存的 Top-K 候选，不能替代完整评测。最终推荐参数仍需要再跑一次 `memory_eval.py` 全量验证。

## 全量复验

使用同一参数重新运行 LoCoMo 全量评测后，结果为：

| Setting | Recall@1 | Recall@3 | Recall@5 | MRR |
|---|---:|---:|---:|---:|
| BGE-M3 + adaptive time-aware + persona gate + importance proxy | 0.329 | 0.492 | 0.562 | 0.439 |

结论：`importance_weight=0.06` 在候选级调参和全量复验中都稳定优于 `importance_weight=0.01`，因此当前推荐使用 `0.06`。
